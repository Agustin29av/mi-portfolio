# Imágenes del portfolio

Coloca aquí tu foto de perfil y screenshots de proyectos.

- `profile.jpg` o `profile.png` — foto de perfil (recomendado: 512×512, formato cuadrado).
- `projects/<slug>.jpg` — screenshots de proyectos (recomendado: 1280×800).

Importalas en componentes con `import profile from '../assets/images/profile.jpg'` o referencialas desde `portfolioData.ts`.
